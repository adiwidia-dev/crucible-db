# Reviewer workspace

**Who sees it:** users whose effective policy grants reviewer authority for at least one connection.

Reviewer authority adds decisions to the normal user workspace; it does not expose administrator settings.

![Reviewer Overview dashboard](../assets/screenshots/reviewer-overview.png){ .docs-screenshot }

## Find requests awaiting review

Use **Overview → Pending review** for the immediate queue. Use **Query Requests** when you need filters or historical context. Only requests within your reviewable connection scope appear as actionable.

## Independence

You cannot approve your own request. If you also have requester permissions, another eligible reviewer must make the decision.

## Review standard

Confirm target, requested scope, SQL or access level, duration, preflight findings, schedule, and operational explanation. A warning needs judgment; a block must be corrected before execution.

Continue with the [Approval flow](approval-flow.md).
