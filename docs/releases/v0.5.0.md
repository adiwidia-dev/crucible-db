# Crucible DB v0.5.0

Released on 29 October 2026.

Crucible DB v0.5.0 adds provider-agnostic OpenID Connect sign-in and makes operational identifiers visible where teams triage governed work.

## Generic OpenID Connect SSO

- Administrators can configure any standards-compliant OpenID Connect issuer, including self-hosted identity services, alongside Google, GitHub, and Microsoft.
- Generic OIDC uses issuer discovery, verified identity claims, encrypted client secrets, and the existing invitation-only account-linking rules.
- The provider setup screen guides administrators through issuer URL, callback URL, scopes, and provider verification before enablement.

## Clearer operational work

- The Operational queue now shows the linked workflow `#ID` beside each status, matching the Query Requests table and direct workflow links.
- Teams can identify and discuss a queue item without relying on its title alone.

## Upgrade from v0.4.3

Back up persistent storage, update the application and native-proxy images together, allow the application startup migration to finish, then reload Octane, Horizon, and scheduler workers:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.5.0
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.5.0
NATIVE_PROXY_EXPECTED_VERSION=0.5.0
```

This release includes an authentication-provider schema migration. Existing Google, GitHub, and Microsoft providers continue to work without reconfiguration. Configure an issuer URL only when adding a generic OIDC provider.

## Release artifacts and verification

The `v0.5.0` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and a Homebrew cask update after the application, database, native, artifact, and documentation gates pass.
