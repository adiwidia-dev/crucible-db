# Crucible DB v0.3.0

Released on 14 October 2026.

Crucible DB v0.3.0 makes postponed review work safe to resume later and lets teams start fresh requests from completed or cancelled work without carrying stale approvals, schedules, execution state, or permissions forward.

## Safe review withdrawal

- A Deployment Batch requester or administrator can withdraw a **Pending review** batch to **Draft** with a required reason.
- Withdrawal immediately removes the batch from active review, increments its revision, prevents stale approval submissions, and records notifications and audit context.
- Statements, targets, schedule, preflight results, and review history remain available for editing and verification before explicit resubmission.

## Editable request reuse

- **Create similar** opens the normal new-request form from a completed or cancelled Deployment Batch or Query Access request without changing the source request.
- Deployment statements, target scope, access transport, access level, duration, title, and context are editable before the new request is saved or submitted.
- Approval decisions, schedules, preflight and execution results, sessions, cancellation state, and notifications are not copied. The current user becomes the requester, and current access and approval policy are evaluated again.
- Inactive or currently unauthorized targets are identified and left unselected instead of being silently removed or reassigned. Source lineage remains visible to authorized users.

## Toolchain refresh

- Frontend dependencies now include React DOM 19.3, Vite 8.3, current Node.js type definitions, and refreshed supporting build packages.
- Documentation now distinguishes editable request reuse from linked Deployment Batch retry and Query Access renewal workflows.

## Upgrade from v0.2.14

This release adds a nullable `copied_from_id` relationship to Query Requests. Back up persistent storage and Redis, update the application and native-proxy images together, allow the application startup migration to finish, then reload Octane, Horizon, and scheduler workers:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.3.0
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.3.0
NATIVE_PROXY_EXPECTED_VERSION=0.3.0
```

Verify that a pending Deployment Batch can return to Draft, completed or cancelled requests offer **Create similar**, unavailable copied targets require an explicit replacement, and the new request receives a fresh approval decision under current policy.
