# Crucible DB v0.2.10

Released on 22 September 2026.

Crucible DB v0.2.10 fixes deletion of cancelled Native Client Query Access requests while preserving the intended request lifecycle and audit record.

## Native Client request cleanup

- Administrators can now delete a cancelled Native Client Query Access request even after it created a native-proxy lease or connection.
- Deleting the request atomically removes its dependent session, native-proxy lease, connection, device authorization, token, and authentication-attempt records.
- Request deletion continues to write the existing query-request deletion audit event before dependent operational records are removed.

## Upgrade from v0.2.9

Apply the bundled database migration, then update the application and native-proxy images together:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.2.10
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.2.10
NATIVE_PROXY_EXPECTED_VERSION=0.2.10
```

Pull and recreate the stack, run migrations, and reload Octane workers. Verify that an administrator can delete a cancelled Native Client Query Access request. See the [production deployment and upgrade guide](../operations/production.md) for backup, readiness, and recovery steps.
