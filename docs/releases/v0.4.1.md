# Crucible DB v0.4.1

Released on 22 October 2026.

Crucible DB v0.4.1 is a security maintenance release. It updates every FrankenPHP build stage to the patched PHP 8.5.12 runtime while preserving the existing application and native-proxy deployment topology.

## Security update

- Development, frontend-build, and production application stages now use the immutable `dunglas/frankenphp:1-php8.5.12` multi-architecture image.
- This remediates CVE-2026-109618 and CVE-2026-109619 in the bundled PHP runtime.
- The native proxy remains a separate Go and distroless image; its build image is updated to Go 1.27.3 to remediate CVE-2026-111943.

## Upgrade from v0.4.0

Back up persistent storage, update the application and native-proxy images together, allow the application startup migration to finish, then reload Octane, Horizon, and scheduler workers:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.4.1
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.4.1
NATIVE_PROXY_EXPECTED_VERSION=0.4.1
```

Verify the running application image reports PHP 8.5.12 before returning the service to normal operation.

## Release artifacts and verification

The `v0.4.1` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and a Homebrew cask update after the application, database, native, artifact, and documentation gates pass.
