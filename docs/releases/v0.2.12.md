# Crucible DB v0.2.12

Released on 29 September 2026.

Crucible DB v0.2.12 keeps Deployment Batch execution history in view while reviewing paginated results and refreshes the application build and static-analysis toolchain.

## Execution-history pagination

- Selecting a new Execution history page on a Deployment Batch detail view returns to the table instead of the top of the page.
- The visit preserves the page state, so long batches remain practical to review without repeatedly scrolling past their statements and metadata.

## Build and tooling refresh

- Development and production frontend build stages now use Node.js 26.
- ESLint 10 uses supported React and import plugins; TypeScript 7 powers type checking alongside the TypeScript 6 runtime that TypeScript-ESLint currently requires.
- Passkeys, Wayfinder, globals, and immutable Docker GitHub Actions pins are updated through the verified dependency workflow.

## Upgrade from v0.2.11

No database migration is required. Back up persistent storage and Redis, then update the application and native-proxy images together:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.2.12
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.2.12
NATIVE_PROXY_EXPECTED_VERSION=0.2.12
```

Pull and recreate the stack, then reload Octane workers. Verify that changing an Execution history page retains the table position on a long Deployment Batch detail page.

## Release artifacts and verification

The `v0.2.12` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and a Homebrew cask update after the application, database, native, artifact, and documentation gates pass.
