# Crucible DB v0.5.1

Released on 20 November 2026.

Crucible DB v0.5.1 is a security and dependency maintenance release. It moves the application runtime to PHP 8.5.13, refreshes the native and Laravel dependency stacks, and preserves release compatibility across the application, frontend, and native proxy.

## Patched application runtime

- Development, frontend-build, and production stages now use the immutable `dunglas/frankenphp:1-php8.5.13` multi-architecture image.
- PHP 8.5.13 remediates CVE-2026-115560 and CVE-2026-126714.
- The production image was rebuilt and its runtime version was verified directly with `php -v`.

## Dependency and toolchain maintenance

- The native build image moves to Go 1.27.4, while the Go 1.26 compatibility and release jobs move to 1.26.11, remediating CVE-2026-97054.
- The native PostgreSQL and SCRAM clients and Go compression library are updated to their reviewed patched releases.
- Laravel Fortify, Horizon, Sail, PHPUnit, Mockery, Vite React, Radix UI, Rollup, Wayfinder, and supporting transitive dependencies are refreshed.
- Composer, npm, and Go vulnerability scans report no known advisories in the released lockfiles and module graph.

## Compatibility fixes

- Application-database migration planning now rejects malformed manager state and invalid port values instead of coercing them.
- Legacy settings redirects are explicitly GET-only, preserving their browser behavior while keeping Laravel 13 and Wayfinder route generation compatible.

## Upgrade from v0.5.0

Back up persistent storage, update the application and native-proxy images together, allow application startup checks to finish, then reload Octane, Horizon, and scheduler workers:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.5.1
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.5.1
NATIVE_PROXY_EXPECTED_VERSION=0.5.1
```

This release does not add an application database migration. The application and native-proxy images should still be upgraded together so their reported and expected versions remain aligned.

## Release artifacts and verification

The `v0.5.1` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and a Homebrew cask update after the application, database, native, artifact, and documentation gates pass.
