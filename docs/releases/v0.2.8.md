# Crucible DB v0.2.8

Released on 18 September 2026.

Crucible DB v0.2.8 is an operational reliability release that keeps System Status focused on runtime health and makes native-proxy readiness consistently visible throughout the authenticated application. It also improves the mobile header without removing any account or operational actions.

## Accurate System Status

- Remove the Wayfinder card from System Status. Wayfinder generates TypeScript route contracts during the frontend build and is not a production runtime service, so checking for generated source files inside a compiled image could incorrectly mark a healthy deployment as unhealthy.
- Keep System Status limited to actionable runtime components: the application runtime, control database, Redis, Horizon, scheduler heartbeat, and native proxy.
- Preserve the page's read-only, scheduler-refreshed model; opening System Status still does not initiate infrastructure probes or expose sensitive configuration.

## Persistent native-proxy visibility

- Share the native-proxy health snapshot and authorized active-connection counts across authenticated pages so the header indicator remains visible after navigating away from Overview.
- Scope connection and instance counts to sessions the current user may see, while administrators retain the workspace-wide operational view.
- Preserve the previous Overview payload during rolling Octane deployments so an old worker and newly built frontend can coexist until workers are reloaded.

## Responsive application header

- Keep the header's operational controls from shrinking or disappearing on narrow screens.
- Hide the redundant account name on phone-sized viewports while retaining the avatar, accessible account identity, notifications, CLI action, native-proxy status, and sign-out action.

## Upgrade from v0.2.7

No database migration or configuration change is required. Back up persistent storage and Redis, then update the application and native-proxy images together:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.2.8
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.2.8
NATIVE_PROXY_EXPECTED_VERSION=0.2.8
```

Pull and recreate the stack, then reload Octane workers. Verify `/health`, System Status, the native-proxy indicator on Overview and another authenticated page, and the compact phone header. See the [production deployment and upgrade guide](../operations/production.md) for backup, readiness, and recovery steps.
