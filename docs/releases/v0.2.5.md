# Crucible DB v0.2.5

Released on 17 September 2026.

Crucible DB v0.2.5 is an urgent reliability release that restores review submission for every governed request type.

## Fixed review submission

- Restore the request revision required when a reviewer approves or rejects a Deployment Batch or Query Access request.
- Keep optimistic concurrency protection in place: a review is still rejected if the request changed after the reviewer opened it.
- Show the review validation message in the interface so a rejected submission is visible and actionable.
- Add coverage for approval and rejection of both request types using the revision delivered by the detail page.

## Upgrade from v0.2.4

No database migration or configuration change is required. Update the application and native-proxy images together when native client access is enabled:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.2.5
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.2.5
NATIVE_PROXY_EXPECTED_VERSION=0.2.5
```

Pull and recreate the stack, then verify that an authorized reviewer can approve and reject one pending Deployment Batch and one pending Query Access request.

## Release artifacts and verification

The `v0.2.5` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and a Homebrew cask update. Publication begins only after the application, application-database, native race, protocol integration, image smoke, and artifact-verification gates pass.
