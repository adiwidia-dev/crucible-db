# Crucible DB v0.2.1

Released on 12 September 2026.

Crucible DB v0.2.1 is a maintenance and supply-chain hardening release for v0.2.0. It keeps the governed database workflows and native-client capabilities introduced in v0.2.0 while refreshing the dependencies and CI tooling that build, test, and publish them.

## Highlights

### Dependency and advisory remediation

- Update the application frontend toolchain, including Inertia Vite integration, React DOM types, TypeScript ESLint, Prettier Tailwind integration, and Lucide icons.
- Update the native-proxy production build image to Go 1.27.1.
- Update the pinned GitHub Actions used for documentation publication, native testing, release artifacts, SBOM generation, and provenance.
- Update `js-yaml` to 4.3.2 and `league/commonmark` to 2.10.1 to remove the advisories reported by the npm and Composer audit tools.

### Safer dependency delivery

- Direct every Dependabot ecosystem to the `develop` branch. Dependency updates are now verified there before a protected pull request promotes them to `main`.
- Continue to test native protocol support across PostgreSQL 14–18 and MySQL 8.0/8.4, including the native image build using its production Go toolchain.

## Upgrade from v0.2.0

This release does not change the control-plane schema, environment-variable contract, or native-proxy configuration.

1. Back up the application storage volume and Redis as part of the normal upgrade procedure.
2. Set both production image variables to the immutable `0.2.1` release tag:

   ```dotenv
   CRUCIBLE_IMAGE=hephaestus/crucible-db:0.2.1
   CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.2.1
   ```

3. Pull and recreate the production stack.
4. Confirm application and Redis readiness, then verify sign-in, queue processing, scheduled work, and one governed database request.

Use the [production deployment and upgrade guide](../operations/production.md) for the complete procedure. The moving `latest` image tags remain available for evaluation only; production deployments should use this immutable tag or an image digest.

## Release artifacts and verification

The `v0.2.1` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and the Homebrew cask update. The release gate reruns the application tests, application-database matrix, native race suite, protocol integration matrix, image smoke tests, and artifact verification before publication.
