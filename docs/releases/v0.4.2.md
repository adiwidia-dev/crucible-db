# Crucible DB v0.4.2

Released on 22 October 2026.

Crucible DB v0.4.2 is a dependency maintenance release. It incorporates the reviewed Dependabot updates into the application and native CLI release workflow without changing the deployment topology or supported runtime contract.

## Dependency updates

- Update `@inertiajs/vite` from 3.9.0 to 3.9.1.
- Update the Radix UI label, select, and dropdown-menu primitives to their current compatible releases for React 19.
- Update the Linux x64 GNU Rollup binary package to 4.64.7.
- Update `goreleaser/goreleaser-action` from 7.2.3 to 7.3.0 while retaining GoReleaser v2.

## Upgrade from v0.4.1

Back up persistent storage, update the application and native-proxy images together, allow the application startup migration to finish, then reload Octane, Horizon, and scheduler workers:

```dotenv
CRUCIBLE_IMAGE=hephaestus/crucible-db:0.4.2
CRUCIBLE_NATIVE_IMAGE=hephaestus/crucible-db-native:0.4.2
NATIVE_PROXY_EXPECTED_VERSION=0.4.2
```

No configuration or database migration changes are required specifically for this dependency maintenance release.

## Release artifacts and verification

The `v0.4.2` tag publishes multi-architecture application and native-proxy images, signed CLI archives and packages, checksums, SBOMs, build provenance, and a Homebrew cask update after the application, database, native, artifact, and documentation gates pass.
