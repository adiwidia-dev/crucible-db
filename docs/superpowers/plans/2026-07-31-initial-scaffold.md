# Initial Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable Crucible DB Laravel 13 scaffold with React/Inertia auth, Laravel Boost, Docker Compose, FrankenPHP/Octane, Redis, and local SQLite-compatible metadata storage.

**Architecture:** Scaffold Laravel in the repository root from a temporary Laravel project, preserving existing docs. Use Dockerized Composer/Node/PHP commands so the host only needs Docker. Use the official React/Inertia starter as the frontend/auth foundation, then add runtime and infrastructure files around it. Keep domain features out of this slice so the baseline is easy to verify.

**Tech Stack:** Laravel 13, Inertia, React, TypeScript, Tailwind CSS v4, Kumo UI, Laravel Boost, Laravel Octane, FrankenPHP, Redis, SQLite-compatible metadata storage, Docker Compose, Mailpit, PostgreSQL and MySQL target databases.

---

## File Structure

- `composer.json`: Laravel PHP dependencies, including Octane and Boost.
- `package.json`: frontend dependencies, including Kumo UI.
- `.env.example`: local defaults for SQLite-compatible metadata storage, Redis, Mailpit, and Octane.
- `Dockerfile`: PHP/FrankenPHP runtime image for app, worker, and scheduler services.
- `compose.yaml`: reproducible local services.
- `.docker/entrypoint.sh`: shared container startup script.
- `.docker/Caddyfile`: FrankenPHP/Caddy configuration.
- `routes/web.php`: starter routes plus a lightweight health endpoint.
- `tests/Feature/HealthTest.php`: verifies the app health endpoint.
- `docs/PROJECT_DECISIONS.md`: update if scaffold implementation changes an existing decision.

- [ ] **Step 1: Add Docker entrypoint**

Create `.docker/entrypoint.sh`:

```sh
#!/bin/sh
set -eu

mkdir -p /app/storage/database /app/storage/framework/cache /app/storage/framework/sessions /app/storage/framework/views /app/storage/logs

if [ ! -f /app/storage/database/crucible.sqlite ]; then
    touch /app/storage/database/crucible.sqlite
fi

exec "$@"
```

Expected: Containers create required writable directories before starting.

- [ ] **Step 2: Add Caddyfile**

Create `.docker/Caddyfile`:

```caddyfile
{
    auto_https off
}

:8000 {
    root * /app/public
    encode zstd br gzip
    php_server
    file_server
}
```

Expected: FrankenPHP serves Laravel from `/app/public` on port `8000`.

- [ ] **Step 3: Add Dockerfile**

Create `Dockerfile`:

```dockerfile
FROM dunglas/frankenphp:1-php8.4 AS base

WORKDIR /app

RUN apt-get update \
    && apt-get install -y --no-install-recommends \
        git \
        unzip \
        libzip-dev \
        libpq-dev \
        default-mysql-client \
        postgresql-client \
    && install-php-extensions \
        pdo_mysql \
        pdo_pgsql \
        redis \
        zip \
        pcntl \
    && rm -rf /var/lib/apt/lists/*

COPY --from=composer:2 /usr/bin/composer /usr/bin/composer
COPY .docker/Caddyfile /etc/caddy/Caddyfile
COPY .docker/entrypoint.sh /usr/local/bin/crucible-entrypoint

RUN chmod +x /usr/local/bin/crucible-entrypoint

ENTRYPOINT ["crucible-entrypoint"]
CMD ["frankenphp", "run", "--config", "/etc/caddy/Caddyfile"]
```

Expected: Image can run the web app and worker commands.

- [ ] **Step 4: Add Compose file**

Create `compose.yaml`:

```yaml
services:
  app:
    build:
      context: .
    command: ["php", "artisan", "octane:start", "--server=frankenphp", "--host=0.0.0.0", "--port=8000", "--workers=2", "--max-requests=500"]
    ports:
      - "8000:8000"
    env_file:
      - .env
    volumes:
      - .:/app
      - crucible_storage:/app/storage
    depends_on:
      redis:
        condition: service_healthy

  worker:
    build:
      context: .
    command: ["php", "artisan", "horizon"]
    env_file:
      - .env
    volumes:
      - .:/app
      - crucible_storage:/app/storage
    depends_on:
      redis:
        condition: service_healthy

  scheduler:
    build:
      context: .
    command: ["php", "artisan", "schedule:work"]
    env_file:
      - .env
    volumes:
      - .:/app
      - crucible_storage:/app/storage
    depends_on:
      redis:
        condition: service_healthy

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 5s
      timeout: 3s
      retries: 10

  mailpit:
    image: axllent/mailpit:latest
    ports:
      - "8025:8025"
      - "1025:1025"

  target-postgres:
    image: postgres:17-alpine
    environment:
      POSTGRES_DB: crucible_target
      POSTGRES_USER: crucible
      POSTGRES_PASSWORD: crucible
    ports:
      - "5433:5432"
    volumes:
      - target_postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U crucible -d crucible_target"]
      interval: 5s
      timeout: 3s
      retries: 10

  target-mysql:
    image: mysql:8.4
    environment:
      MYSQL_DATABASE: crucible_target
      MYSQL_USER: crucible
      MYSQL_PASSWORD: crucible
      MYSQL_ROOT_PASSWORD: crucible_root
    ports:
      - "3307:3306"
    volumes:
      - target_mysql_data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost", "-ucrucible", "-pcrucible"]
      interval: 5s
      timeout: 3s
      retries: 20

volumes:
  crucible_storage:
  target_postgres_data:
  target_mysql_data:
```

Expected: Compose defines app, worker, scheduler, Redis, Mailpit, and target databases.
